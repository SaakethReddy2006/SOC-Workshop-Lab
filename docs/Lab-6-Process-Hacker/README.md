# ⚡ Lab 6 – Dynamic Malware Analysis Using Process Hacker

---

## 📖 Overview

Process Hacker is an advanced process monitoring tool used to observe running processes, services, memory usage, network activity, and system resources.

In this lab, participants execute a sample in a controlled environment and monitor its runtime behavior using Process Hacker to identify suspicious activities.

---

## 🎯 Learning Objectives

- Understand dynamic malware analysis
- Monitor running processes
- Analyze process trees
- Observe suspicious behavior
- Identify Indicators of Compromise (IOCs)

---

## 🛠️ Tools Used

| Tool | Purpose |
|------|---------|
| Process Hacker | Process Monitoring |
| Windows 10 | Analysis Environment |
| VMware Workstation Pro | Safe Malware Execution |
