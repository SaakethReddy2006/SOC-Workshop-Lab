# ⚙️ Installation Guide – VirusTotal

VirusTotal is a cloud-based service, so no software installation is required.

---

# 📋 Requirements

- Internet Connection
- Web Browser

---

# Step 1 – Visit VirusTotal

Open:

https://www.virustotal.com/
