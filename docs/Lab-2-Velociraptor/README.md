# 🦖 Lab 2 – Forensic Investigation of a Compromised System Using Velociraptor

---

## 📖 Overview

Velociraptor is an open-source Digital Forensics and Incident Response (DFIR) platform designed for endpoint visibility, forensic artifact collection, and incident response investigations.

In this lab, participants create an Offline Collector, execute it on a Windows endpoint, and collect forensic artifacts without installing a permanent endpoint agent.

---

## 🎯 Learning Objectives

- Deploy Velociraptor Server
- Generate an Offline Collector
- Configure artifact collection
- Execute forensic evidence collection
- Understand endpoint DFIR workflows
