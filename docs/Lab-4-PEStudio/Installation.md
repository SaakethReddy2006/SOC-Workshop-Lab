# ⚙️ Installation Guide – PEStudio

---

# 📋 Requirements

- Windows 10/11
- Internet Connection

---

# Step 1 – Download PEStudio

Visit:

https://www.winitor.com/

Download the latest version.

# Step 2 – Extract ZIP

Right-click the downloaded ZIP.

Select:

```
Extract All
```



---

# Step 3 – Open PEStudio

Open the extracted folder.

Double-click:

```
PEStudio.exe
```

No installation is required.
