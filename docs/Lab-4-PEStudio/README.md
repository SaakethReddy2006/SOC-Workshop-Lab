# 🧬 Lab 4 – Static Malware Analysis Using PEStudio

---

## 📖 Overview

PEStudio is a static malware analysis tool that inspects Windows Portable Executable (PE) files without executing them.

In this lab, participants analyze a suspicious executable to identify indicators such as imported APIs, suspicious strings, embedded resources, entropy, and potential malicious behavior.

---

## 🎯 Learning Objectives

- Understand static malware analysis
- Analyze Windows PE files
- Identify suspicious API imports
- Detect Indicators of Compromise (IOCs)
- Interpret PEStudio findings
