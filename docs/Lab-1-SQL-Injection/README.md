# 🌐 Lab 1 – Forensic Investigation of Application Security Incidents: SQL Injection Attack

---

## 📖 Overview

SQL Injection (SQLi) is one of the most common web application attacks that allows attackers to manipulate database queries by injecting malicious SQL statements into user input fields.

In this lab, participants investigate a vulnerable web application, understand how SQL Injection works, observe its impact on the backend database, and learn the importance of secure input validation and parameterized queries.

---

## 🎯 Learning Objectives

By completing this lab, you will be able to:

- Understand SQL Injection attacks
- Identify vulnerable input fields
- Observe database manipulation through SQL Injection
- Understand the forensic indicators of SQL Injection attacks
- Learn mitigation techniques
