# 🦠 Lab 5 – Suspicious File Analysis Using VirusTotal

---

## 📖 Overview

VirusTotal is a cloud-based malware analysis platform that scans files and URLs using multiple antivirus engines and threat intelligence sources.

In this lab, participants upload a suspicious file, review detection results, analyze behavioral indicators, and interpret threat intelligence provided by VirusTotal.

---

## 🎯 Learning Objectives

- Analyze suspicious files safely
- Interpret antivirus detection results
- Understand file reputation
- Explore Indicators of Compromise (IOCs)
- Perform basic threat intelligence analysis

---
